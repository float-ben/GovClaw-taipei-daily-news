4. 視力模糊伴隨頭痛？當心「白內障」引爆「青光眼」

播報稿 / 引用重點
長輩們視力模糊可千萬不要只以為是老花或白內障！醫師警告，白內障在成熟過程中如果過度膨脹，容易把眼睛狹窄的排水通道堵住，引發急性青光眼甚至面臨失明危機。醫生建議，五十歲以上、有高度遠視或家族病史的市民，每年都應定期接受完整的眼科檢查，別讓沉默的視力小偷找上門！

選錄原因：針對高齡化社會常見的眼科共病，提醒市民注意白內障膨脹引起青光眼的盲性危機，具備高實用性的醫療科普價值。
